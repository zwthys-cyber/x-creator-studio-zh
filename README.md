# X Creator Studio 中文适配 v0.4

仅适配 X iOS 创作者工作室菜单，不改变资格状态或解锁收益功能。

## v0.4：针对真实 Jetfuel 页面

用户的 v0.3 诊断已经确认页面匹配成功，但原生/网页替换为零：文字来自 17 个 JetfuelSDK.TextDisplayView / 私有 TextInkView，节点和网页均为零。旧版能从 accessibilityLabel 识别文案，却没有对应文字设置接口；修改可访问性标签不会改变自绘英文。

v0.4 仅对已匹配创作者工作室页面中、类名与诊断一致且完整菜单文案在词典内的 TextDisplayView 处理：隐藏其 TextInkView 子视图，在原文字框内加入中文 UILabel。保留原行、背景、图标、箭头、布局和手势；中文标签不接收触摸。退出页面或控件复用为其他内容时，移除中文标签并还原原英文绘制子视图的透明度和可访问性标签。字体根据原文字框大小估计，提供系统明暗配色和单行缩放；并非恢复 Jetfuel 私有文字属性。

UIKit、图层节点和网页路径保留。未对任意 Swift 私有存储进行写入。

## 巨魔注入器

下载成功任务的 XCreatorStudioZH-v0.4，解压出 XCreatorStudioZH.dylib。移除旧版插件，注入新版到 X 主程序，按注入器提示完成安装。彻底退出 X，再从桌面打开并进入创作者工作室。兼容修改 Bundle ID 的多开包。不要注入应用扩展或其他应用。

启动显示 v0.4 加载提示，右上角保留“中文诊断 v0.4”按钮。若仍有英文，点击按钮→复制诊断，并提供仍为英文区域的截图。重点查看新增“Jetfuel 自绘替换”计数。诊断只显示类名、词典菜单项和计数，不包含帖子正文，不联网、不自动上传。

## 验证范围与当前状态

GitHub Actions 编译 arm64/arm64e，检查架构/临时签名，并运行合成 iOS 模拟器 UI 检查。新增仿真实类名的17项自绘菜单：无 text/attributedText 设置接口、中文标签生成、英文绘制隐藏、点击目标/几何保持、重复扫描、控件复用、离开页面还原和明暗截图。既有 UIKit/图层/WebKit/可点击诊断检查继续执行。

这些检查不等于真实 X 或设备验证。v0.1–v0.3 的实际英文未被成功替换；v0.3 诊断入口已由用户确认可用。v0.4 的真实设备结果仍待用户确认，不能仅凭 CI 宣称适配成功。

原始 IPA 参考任务：https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42738640961 。本项目未读取其 IPA 明文，不包含 IPA、凭据或解密材料。

## 开发约束

所有编译、项目运行、自动测试和产物验证仅在 GitHub 托管 Actions runner 上进行。当前服务器只调用 GitHub API 和编辑文件，不运行项目、不安装编译依赖、不做测试。源码通过 GitHub API 维护；公开产物只含插件、文档和合成测试结果/截图。
