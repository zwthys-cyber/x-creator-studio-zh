# X Creator Studio 中文适配 v0.3

为 X iOS 的创作者工作室菜单提供简体中文。支持标准 UIKit 文字、Texture 风格节点、CATextLayer 和 WKWebView 文本。仅匹配页面标题及至少一个专属菜单特征后处理词典内的完整文案，不改变资格状态或解锁收益功能。尚未证明真实 X 页面使用上述哪种渲染方式。

## 巨魔注入器

从成功的 Actions 任务下载 XCreatorStudioZH-v0.3，解压出 XCreatorStudioZH.dylib。移除上一版插件，再用巨魔注入器将新版注入当前安装的 X 主程序，按工具提示完成安装。退出 X 后从桌面重新启动。多开包修改 Bundle ID 也可启用；插件不要注入应用扩展或其他应用。

启动显示加载提示，右上角保留“中文诊断 v0.3”按钮。点击直接展开本机诊断面板，不再使用三指长按或依赖 X 页面弹窗。支持“复制诊断”和刷新；面板可滚动，按钮再次点击可关闭。独立浮窗不抢占 X 的主窗口，控件之外的触摸穿透。诊断包含控件/节点类型、已匹配的词典菜单项、替换计数和网页错误码，不包含帖子正文，不联网、不自动上传。

## v0.3 更新与真实反馈

用户确认 v0.2 已加载，但真实页面仍为英文且三指长按没有弹窗；不能将 v0.2 模拟器通过描述成真实 X 适配成功。v0.3 补充 CALayer 关联文字节点及 subnodes 树（包括无独立 UIView 的文字），通过独立可点击按钮提供稳定诊断，并允许仅凭两项专属菜单特征识别网页/原生页面。节点树去重、防循环且有数量/深度限制。真实设备效果仍待反馈。

## v0.1 的已知问题

旧版限制了原始 Bundle ID，只扫描 UILabel/UIButton，且要求四个菜单特征同时存在；在克隆包、网页、非标准文字节点或部分菜单未加载时可能完全不工作。v0.3 去除 Bundle ID 限制，放宽为标题加一个专属特征，补充不同文字路径和加载提示。用户已反馈 v0.1 实际页面仍显示英文。

## 验证范围

GitHub Actions 编译 arm64/arm64e，检查架构和临时签名；使用合成 iOS 模拟器页面验证原生文字、空白归一化、文字样式、仿 Texture 节点、图层关联和子节点循环、CATextLayer、WKWebView、重复扫描、无关页面排除、诊断按钮点击命中与面板打开/关闭、触摸穿透和报告正文排除。

这些检查不等于真实 X IPA 或设备验证。真实页面仍可能使用其他绘制方式，插件未成功加载也无法翻译。原始 IPA 参考任务：https://github.com/zwthys-cyber/ipa-decrypt-lab/actions/runs/42738640961 。插件不包含 IPA 或解密材料，未读取该任务的 IPA 明文。

## 开发约束

所有编译、项目运行、自动测试和产物验证仅允许在 GitHub 托管 Actions runner 上进行。当前服务器只编辑文件和调用 GitHub API，不运行项目、不安装编译依赖、不做测试。源码通过 GitHub API 维护；公开产物仅含本项目插件和合成测试结果。
